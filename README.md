# Bilibili Accelerator for Android

**一个致力于改善哔哩哔哩客户端视频加载体验的 LSPosed 增强模块。**

本项目是 [realzza/bilibili-accelerator](https://github.com/realzza/bilibili-accelerator) 的非官方 Android 移植版。

你是否遇到过明明网速很快，但看 B 站视频时依然频频卡顿、一直在转圈缓冲的情况？这通常是因为 B 站为了节省成本，为你分配了一些质量不稳定的边缘节点（甚至是他人的个人宽带节点）来加载视频。
本模块通过在后台智能接管 B 站客户端的视频加载过程，将这些容易卡顿的低速节点无缝切换至**官方的高速 CDN 服务器**，从而让你告别视频缓冲的烦恼。同时，模块内置了直观的**实时数据看板**，加速效果一目了然。

---

## 核心特性

本模块在底层对视频流与直播流请求进行智能拦截、重定向与并发调度，全面保障播放体验：

* **PCDN 深度识别与过滤**：智能阻断低质 P2P/PCDN 节点与非标端口，强制回退至官方优质骨干网；支持点播视频与直播流的 PCDN 过滤，识别并提取直播源站参数（`xy_usource` 等）动态恢复真直播源。
* **MCDN 调度策略颗粒度**：支持 `proxy-all`（通过云厂商官方 CDN 全量中继代理）、`proxy-v1`（仅针对资源接口走代理，常规流直连主镜像）、`replace`（全量直接替换为主镜像）多档位自适应调度。
* **Akamai 节点签名保护**：自动识别海外与官方 Akamai 鉴权节点，默认保留专属 HMAC Token 签名安全放行（`akamai-pass`），杜绝因修改 Host 导致的 HTTP 403 播放失败。
* **BTR 多源并发分片加速（Bilibili Thread Ripper）**：
  * **自动动态线程调节（Auto Concurrency）**：开播与 Seek 冲刺阶段以 8~12 线程并发拉取，平稳后自动回落至基准并发并收缩在途滑动窗口；设置中支持开启/关闭 Auto，并提供自定义滑块/选项（2~16 线程灵活切换）。
  * **自适应切片尺寸（Dynamic Chunk Size）**：根据视频总体积与清晰度在 256KB~2MB 间自适应匹配分片大小，音频采用 128KB 极低延时切片，高码率与 4K 大视频自动放大至 1MB~2MB，大幅降低高吞吐下的并发 HTTP 请求与头部握手开销。
  * **自定义白名单 CDN 节点池**：支持用户在设置中自定义配置、增删多达 32 个白名单 CDN 镜像节点，允许海外与专线用户灵活指定参与并发拉取的节点池。
  * **OkHttp 共享连接池与 HTTP/2 多路复用**：底层请求全面升级为高性能 OkHttp 栈，支持 HTTP/2 多路复用与长连接复用，杜绝跨分片重复 TCP/TLS 握手。
  * **多源 CDN 并发拉取**：智能合成安全的大陆同源 UPOS 镜像与自定义候选池，解决客户端备用地址缺失或调用时序倒置问题，实现真正的跨 CDN 并发负载。
  * **0KB 空响应包与截断熔断**：严格校验探测包与分片字节完整性，遭遇 0KB 空包或截断时立即熔断惩罚并自动无缝 Failover 故障转移，杜绝播放器假死转圈。
  * **音频轨道隔离与防混流**：精准识别 DASH 独立音频流（302xx），采用 128KB 极低时延切片与 2 线程隔离并发，杜绝与视频大分片争抢带宽，彻底解决音画不同步。
* **数据可视化看板**：配有直观的实时统计面板、最近拦截日志与分流详情染色。

## 安装与激活

### 前置要求

* 已 Root 的 Android 设备
* 已安装并激活支持新版标准的框架（如最新版的 [LSPosed](https://github.com/LSPosed/LSPosed) 或 Vector 等）
* 哔哩哔哩官方客户端（支持标准版 / 概念版 / 国际版 / HD 版等）

### 激活步骤

1. 下载最新版的 `app-release.apk` 并安装。
2. 打开你的框架管理器（如 **LSPosed Manager**），在“模块”列表中找到 **Bili Accelerator** 并勾选启用。
3. 在模块的作用域设置中，勾选你需要加速的 B 站客户端（如：`tv.danmaku.bili` / `com.bilibili.app.in` / `com.bstar.intl` 等）。
4. **强行停止**（杀掉后台）哔哩哔哩客户端。
5. 重新打开哔哩哔哩。
6. 打开本模块的 APP，若顶部状态显示 **“✅ 已激活”**，即代表配置成功。此时去 B 站随意播放一个视频，即可在面板中观察到拦截与重定向的计数正在增加。

## 遇到问题？

**Q1: 打开模块 APP 显示“未激活”怎么办？**

* 请检查框架管理器中是否已勾选启用本模块，并且**正确勾选了哔哩哔哩客户端作为作用域**。
* 每次更新模块或修改作用域后，必须**强行停止**（杀掉后台）哔哩哔哩客户端，然后重新打开才会生效。
* 如果确认操作无误但依然显示未激活，请尝试重启手机或重启框架服务。

**Q2: 播放视频时一直转圈缓冲，或者提示加载失败？**

* 可能是 B 站服务器临时调整了策略，或者你的网络运营商对我们重定向后的高速节点连接不佳。
* 部分极旧或最新的 B 站客户端版本可能会更改底层的播放机制。建议你在框架中暂时关闭本模块，排查是否为网络本身的问题。如果确认是模块导致，请在 Issue 中反馈你使用的 B 站版本号。

**Q3: 播放了视频，但面板里的拦截/重定向统计数据一直为 0？**

* 请先确认模块状态是否为“已激活”。
* 在非高峰时段或播放冷门视频时，B 站可能本身就为你分配了官方的优质 CDN，没有触发模块的拦截规则，此时计数不增加属于正常现象。
* 如果持续多天、播放任何视频都不增加，可能是 B 站客户端的更新导致模块的拦截机制失效，欢迎你携带日志向我提交 Issues，并请关注模块的后续更新。

## 编译指南

如果你想自行编译此项目：

1. 使用 **Android Studio** 打开 `bilibili-accelerator-android` 项目。
2. 等待 Gradle 同步完成后，点击菜单栏：**Build > Build Bundle(s) / APK(s) > Build APK(s)**。
3. 或者在终端运行以下命令：
```bash
# 构建正式 Release 版本
./gradlew assembleRelease

# 或构建开发 Debug 版本
./gradlew assembleDebug

```

4. 编译成功后，在 `app/build/outputs/apk/release/` 目录下获取 `app-release.apk` 并安装。
